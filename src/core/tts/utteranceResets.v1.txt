# 山岚（matcha）「语句重置」词表。每行一个词：合成前在该词前把句子切成两段，
# 各自独立合成再拼接，让这个词重新落到新语句的开头。
#
# 与零宽边界 U+200B 的区别：U+200B 只强制文本前端重新做最长匹配，整句仍然是
# 一次合成；长句韵律照样会把词首音节压成含混的轻声。词首静音边界、词尾边界、
# 双端边界、词内停顿都试过，均不稳定（见 polyphones.v1.txt 的地盘注释）。
# 真实 WASM 试听结论（scripts/out/audio/reset/listen.html）：
#   地盘：单独念 di4 对 / 语句重置 di4 对 / 整句一次合成听成 de。
#   便宜：连单独念都不对，属音素层 pian2+yi2 合并，不归本表管。
# 所以本表只收「韵律压字」这一类，不收音素或音素连读问题。
#
# 运行时：pronunciationGuard.ts 在词前插入 U+2060；worker 仅在
# modelType === 'matcha' 时按该标记切分、分段合成并拼接（段间 120ms 静音）。
# 其他音色只把标记当 OOV 去掉，音频不变。
#
# 新增词必须满足：有完整反馈原句、有单独念 / 整句 / 重置三组真实 WASM 试听
# 结论，且确认改动词首边界仍救不回来。切勿把「便宜」这类音素问题写进来。
#
# 2026-11-11 第六轮：三字「X地盘」与「地盘」同属长句韵律压字，不是音素问题。

# 「地」仍会被压成含混的 de，所以必须同步登记在本表。
