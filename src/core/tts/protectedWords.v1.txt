# 山岚（matcha）整词保护表：每行一个必须整体命中的词。
#
# Matcha 文本前端按词典做最长匹配，只要前一个汉字与目标词的首字能组成更长的
# 词条，目标词就会被拆开并落回单字读音。真实 WASM 日志（debug=1）：
#   '学会计' -> '学会' -> 'xue2 hui4 ' + '计' -> 'ji4 '   （会计应读 kuai4）
# 单字兜底恰好就是用户听到的错音：便 bian4、地 de、会 hui4。
#
# 运行时在这些词前插入零宽边界 U+200B。WASM 前端会把它当作 OOV 跳过
# （'OOV word skipped'），不产生任何 token、不改变音频时长，但它会强制前端
# 从保护词重新开始最长匹配，因此不受整书 overlay、缓存旧构建或邻近抢词影响。
#
# 规则：实现按字数从长到短处理，一个词被更长的保护词包含时（会计 / 会计师）
# 不再单独插入，只在长词外边界插入。切勿加入「便宜」这类会切断「占便宜」、
# 而本身没有正确读音风险的短词。
#
# 2026-11-11 第六轮：把「便宜」词族与三字「X地盘」整词纳入保护。
# 前五轮只保护 占便宜 / 地盘，同族词一旦被前一个汉字凑成更长的词条就会
# 落回单字兜底（便 bian4 / 地 de）。3 字长词排在 2 字「地盘」之前，
# 由 cover 规则保证不在长词内部再插 U+200B；抢地盘 / 占地盘 同时登记在
# utteranceResets.v1.txt，否则 applyUtteranceResets() 会因「更长的保护词」
# 跳过 U+2060，长句韵律压字会复发（见 pronunciationGuard.ts:108）。
