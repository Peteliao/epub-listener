## 转换过程

1. 从原始 77MB 文本中按固定规则抽样，不保留全书正文；`g2p` 只保留多音字命中且左右文长度受限的样本。
2. 拼音记法统一为项目内部格式：`ü → v`、轻声记为 `5`（无调号）。
3. `prosody` 只保留 `#3` 边界，并要求右分句以 `但是/可是/然而/因此/于是/那么/如果/……` 等连接词开头；不含完整长句语料。
4. 频次表只保留字 → 读音 → 次数，不保留原始句子或文档标识。
5. 所有派生文件均以 `# 来源`、`# 用途` 注释或 `_source`/`_usage` 字段自描述。

转换脚本未入库；上述指纹用于确认当前文件与 2026-11-23 转换结果一致。

## 允许的用途

- `npm run audit:external-data`：把外部读音与当前有效词典逐条对照，输出人工复听队列；**不自动改表**。
- `tests/ExternalData.test.ts`：验证派生样本格式、记法归一化和 `#3` 连接词边界落在 `SpeechPhrasing` 规则集合内。
- 研究多音字先验排序、韵律边界规则覆盖，不把外部数据当作黄金标签。

## 禁止的用途

- 不进入运行时词典、模型训练集、应用资源包或对外发布的评测集。
- 不以本目录数据直接覆盖 `polyphones.v1.txt`、`phraseReadings.v1.txt` 或整书 overlay。
- 不在未确认授权前把派生样本提交到公开镜像、数据集仓库或商业发行物。

## 回退

删除本目录即可回退。运行时、测试门禁（除 `audit:external-data` advisory 外）和构建均不依赖它；`README.md` 的对应章节需同步删除授权说明。
